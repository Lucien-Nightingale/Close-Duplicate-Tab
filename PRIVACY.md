# Privacy Policy

This extension is designed to run entirely on-device.

## What data is processed
- **Tab URLs and titles** are read via the Chrome `tabs` permission in order to detect and close duplicate tabs.
- **User settings** (rules and preferences) are stored using Chrome `storage`.

## What data is NOT collected
- No analytics.
- No tracking.
- No advertising identifiers.
- No server-side processing.
- No sale or sharing of data.

## Data storage
- Settings are stored in **Chrome sync storage** (`chrome.storage.sync`) so your preferences can sync across devices.
- A local backup is also stored in **Chrome local storage** (`chrome.storage.local`) to reduce the chance of losing settings after updates or sync issues.
- All stored data stays in your browser profile and is not transmitted by this extension.

## Network access
- The extension does **not** make network requests and does **not** load remote code.

If you have questions, open an issue in the GitHub repository.
