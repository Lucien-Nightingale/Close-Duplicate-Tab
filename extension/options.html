Automation

Delay: seconds
When enabled, the extension will automatically close duplicates after the specified delay. The close logic respects all current rules and protections (Pinned / Groups / Whitelist / Blacklist). The timer resets when you switch to a different window or when settings change.
Some suspender extensions replace a tab URL with a wrapper page like chrome-extension://<extId>/suspended.html#...&uri=<originalUrl>. When enabled, this extension will extract the original URL (from uri=/url=) and use it for duplicate detection and rule matching.

Rules

Default: unchecked — blank/new tabs are ignored (not counted, not closed).
Blacklist (default enabled)
Each line is a case-insensitive pattern.
You can use either:
• URL fragment (literal): no escaping needed. Example: youtube.com/watch?v= or tw.yahoo.com
• Regex (evaluated first): re:<pattern> / regex:<pattern> / /pattern/flags
Examples: re:^https?://(www\.)?youtube\.com/watch\?v=
Note: Regex always forces i (case-insensitive). Flags g/y are ignored for stable matching.
Matching order: Regex first, then URL fragment.

Manual rules
Rule format: <host> => <extractorRegex>
<host>: one or more host specs separated by commas, e.g. youtube.com, youtu.be (domain suffixes) or an explicit regex (re:(^|\.)youtube\.com$).
<extractorRegex>: must be an explicit regex using re:, regex:, or /.../flags. The first capture group (if present) becomes the key.
Precedence: manual → auto.
Extended syntax: <extractorRegex1> <=> <extractorRegex2> => <canonicalTarget>
The <=> operator means the extractor regexes are equivalent alternatives.
If <canonicalTarget> is provided, the extension will prefer keeping the tab whose URL already matches the canonical target.
If <canonicalTarget> is omitted (or empty), no redirection preference is applied.
